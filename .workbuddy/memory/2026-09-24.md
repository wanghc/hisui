## 五方布局面板标题高度统一（iHOS/vben 与 pure）

**问题**：五方布局（layout）面板标题高度，iHOS(vben) 展开 46px / 折叠 44px，pure 展开 48px / 折叠 46px。目标全部 46px。

**关键结论**：用户所说的「iHOS风格」= vben 主题（git 提交历史验证：iHOS 相关提交均改 less/vben/）。

**根因**（用 playwright 无头浏览器实测 5 套主题确认）：
- vben 折叠 44px：`less/vben/layout.less` 中 `.layout-expand .panel-title{height:36px}` + header padding 3px + 上下 border 各1px = 44
- pure 展开 48px：`less/pure/layout.less` 中 `.layout>.panel.layout-panel>.panel-header{padding:4px 5px}` + title 38px + border 2px = 48

**修改**：
1. `less/pure/layout.less`：layout 面板 header padding `4px 5px`→`3px 5px`（展开 48→46）；panel-icon `margin-top:-8px`→`-9px`（保持图标与文字垂直居中）
2. `less/vben/layout.less`：`.layout-expand .panel-title` `height:36px`→`38px`（折叠 44→46）
3. 重建 `dist/css/hisui.pure(.min).css`、`hisui.vben(.min).css`（ gulp 3 无法跑 Node22，用项目内 less@2.7.3 + clean-css 复刻 gulpfile 的 min-css-pure/min-css-vben 流程：concat lessArr+beautyscroll → less/{theme}/hisui.min.less → 编译压缩，gulp.src 会跳过不存在的 less 文件需 filter）
4. `dist/readme.md` 增加 2026-09-24 更新日志

**实测复检**：pure 46/46 ✓，vben 46/46 ✓（default/lite/lightblue 本就 36/37 未动，不在需求内）。

**其他**：折叠条总高由 JS `$.hisui.styleCodeConfig.collapsedHeight` 控制（pure/vben 均 56），与 CSS header 高度独立，无需改动。playwright-cli 会话在 shell 调用间不持久，直接写 Node 脚本调 playwright-core 更可靠；file:// 协议被拦截需走本地 HTTP 服务。
