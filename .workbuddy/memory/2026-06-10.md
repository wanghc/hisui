### 新增 CSS 样式类 `accordion-panel-plain`（原名 `accordion-panel-style`）
- **文件**: `less/accordion.less`（末尾）、`less/vben/accordion.less`（末尾）
- **用途**: 加到 `hisui-accordion` 容器上，使手风琴外观与三面板（`hisui-panel`）风格一致
- **核心改动（默认主题）**:
  - 整体边框透明，面板间距 margin-bottom: 6px
  - header 加圆角（4px 4px 0 0），主色描边，折叠箭头换黑色版本
  - body 白色背景 + 黑色文字 + 下圆角
  - 折叠态 header 四角全圆；选中 header 标题加粗
- **vben 主题差异**: 边框用 transparent（变量），箭头用 icon font（::before），尺寸与 vben 原 header 保持一致（height 43px）
- **演示**: `doc/pages/accordion.php` 手风琴示例已加上该类
- **构建**: `"C:\Program Files\nodejs\node.exe" node_modules/gulp/bin/gulp.js min-css`（Node 22 不兼容 gulp 3，必须用系统 Node 11）
  - vben 单独重编：`gulp min-css-vben`
