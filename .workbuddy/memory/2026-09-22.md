# 2026-09-22

## 修复 vben 风格下 `$.hisui.switchTheme` undefined 报错

- **现象**: `jquery.hisui.min.js` DOM ready 时报 `Uncaught TypeError: Cannot read properties of undefined (reading 'switchTheme')`
- **根因**: `src/hisui.js` 尾部的 ready 块 `(function(window, jQuery){...})(window, jQuery)` 之外，直接用全局 `$` 注册 `$(function(){...})`。宿主页面在 hisui 加载后、DOM ready 前二次加载 jQuery 覆盖全局 `$`，ready 回调执行时 `$.hisui` 即为 undefined（仅 vben + HISUITheme 时触发调用）。`src/parser.js` 的 ready 块在 `(function($){...})(jQuery)` 闭包内不受影响，故仅此一处报错。
- **修复**: `src/hisui.js` ready 块包进 `(function($){...})(jQuery)` 闭包捕获打包时的 jQuery，且 switchTheme 调用前判空。
- **构建**: `gulp min-js` 需用系统 Node 11.15.0（gulp 3.9.1 与 managed Node 22 不兼容）。产物已验证：`src/jquery.hisui.src.js`、`dist/js/jquery.hisui.js`、`dist/js/jquery.hisui.min.js`。
- **附带**: `dist/readme.md` 更新日志新增 2026-09-22 条目。
- **宿主页面侧建议**: 排查页面是否重复引入两个版本 jQuery（如 jquery-1.11.3 + jquery-1.8.0），库已容错但重复加载仍有其它隐患。
